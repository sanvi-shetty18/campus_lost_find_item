# 🏫 Campus Lost and Found Platform

A web-based platform designed for students to report and recover lost items on campus. This application helps bridge the gap between finders and owners by centralizing all reports in one place.

## ✨ Features
* **Report Lost Items:** Students can post details about items they've misplaced.
* **Report Found Items:** Users can log items they've found around campus.
* **Item Categorization:** Browse items by category (Electronics, Documents, Accessories, etc.).
* **Real-time Updates:** View the most recent reports on a centralized dashboard.

## 🛠️ Tech Stack
* **Backend:** Python (Flask)
* **Database:** MongoDB
* **Frontend:** HTML5, CSS3 (Bootstrap)
